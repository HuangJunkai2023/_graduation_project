# 提交前抽样复核与 Windows 复现

Codex 按 seed 3801 分层抽取正式测试集24题，逐条复核B1与B3的48个首次输出。作出判断时使用遮蔽配置和原评分的记录，核对原文、引用和预期动作。48条输出的适用字段全部与原评分一致，包括32项完整正确性、84项陈述级引用支撑、36项版本判断、16项合理拒答及32项误拒答。两次核查共享助手工作流。抽样中没有遇到首次引用校验失败，结果仅覆盖入样输出。

代表例包括 test-005 的两个部分回答，证据支持试验场布置和监测描述，但回答遗漏对零部件变形、破损及松动的检查。test-050 的一个回答混入另一装置的严格下限。test-079 的两个回答引用表格内容，在标准及长度对象不明时仍提供实质结果，按预期动作应先澄清。

在项目现有Windows环境，默认编码模式与显式UTF-8模式均为109/109通过。向量、题集、语料、程序和提示词冻结校验通过。用正式首次结果及归档评分复算主指标、分层指标和成对区间，汇总与归档一致，本次复算零API调用。

抽样方法及结构化结果见 [review_sample.py](review_sample.py) 和 [submission_recheck.json](submission_recheck.json)。遮蔽材料、映射、原文定位和逐条判定保存在本机受控目录 `project/qa_system/runtime/research/submission_recheck/`。
