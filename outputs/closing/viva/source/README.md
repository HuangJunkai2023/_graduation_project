# Viva presentation source

The editable presentation uses the retained SWJTU native slide design. Its 15 main slides and three backup slides are populated from the completed scored study, selected calibration, the masked recheck, source-bound failure cases and an actual local interface screenshot. The speaking plan totals 436 seconds.

`build_viva.py` writes a PPT Master round-trip page plan, native-editable SVG content and bilingual notes. It also writes the matching Chinese–English script and question bank. It requires completed measured results and a source-bound case file.

Run from the repository root after importing the retained PPTX with PPT Master's `pptx_to_svg.py --roundtrip --inheritance-mode both`.

The retained source is `outputs/proposal-defense/v7-5min-visual/OCS_Proposal_Defense_EN_5min_SWJTU_Visual.pptx`. Import it into a fresh workspace before running the builder. The delivered `authoring-svg-flat/`, `images/`, `notes/`, `page_plan.json` and `animations.json` also preserve the exact final authoring overlay. Native round-trip payloads are regenerated by importing that original source through PPT Master.

```powershell
& ./project/qa_system/.venv-win/Scripts/python.exe -X utf8 outputs/closing/viva/source/build_viva.py --workspace project/qa_system/runtime/closing_ppt_workspace --summary project/qa_system/runtime/research/measured_results.json --calibration project/qa_system/runtime/research/calibration/closing-v2/selected.json --cases project/qa_system/runtime/research/cases_for_report.json --screenshot outputs/closing/video/recording/answer-with-citations.png --output-dir outputs/closing/viva
```

Refresh the workspace authoring summary, run the round-trip SVG quality checker, and export with `svg_to_pptx.py --roundtrip --primary-language en-US`. Copy the exported PPTX to `OCS_Viva_EN.pptx`, then run the PPTX delivery checker and text read-back. The notes contain both languages as requested. Narration and automatic slide advancement are disabled.

Convert the final PPTX to PDF with local LibreOffice using a dedicated profile. Run `render_previews.py` to make the eighteen page previews, overview and page-boundary check. The local PowerPoint/LibreOffice render should be checked again after subsequent edits.

`validate_final.py` confirms the final eighteen-slide PDF, slide-to-note relationships and bilingual note alignment, then snapshots the authoring overlay and writes `validation/final_validation.json`. The final package checker reports an inherited font-portability advisory for Microsoft YaHei and Japanese theme font declarations. The local render has no observed font/layout defects. Font availability on another computer remains unverified.

The final metrics table and RQ findings are measured observations from the frozen five-configuration study. The slides retain assistant source-review provenance, the shared author/evaluator limitation, six-document question coverage and the absence of verified same-family formal edition pairs. Slide 11 locates the torque-instrument case in the original PDF. Slide 13 identifies BM25 as the best-supported default for this corpus and retains Hybrid as an option.
