# 开题答辩问答参考

对应交大模板五分钟版。回答以正式报告和2026年11月4日已记录证据为界；不得把目标、代码存在或合成检查说成正式性能结果。

## 1. 为什么不让 DeepSeek 直接回答？

直接调用可以产生流畅文本，但无法仅凭输出判断它依据的是哪个正式版本，也不能保证保留数值、单位及适用条件。本项目让模型基于可追溯证据回答，并评价版本错误和拒答。RAG 也不能自动保证正确，仍需原文核对和人工评分。

请参照本版对应主题页或第16–20页备份。

## 2. 为什么选择 RAG 而不是微调？

本课题需要保留可更新文档、版本和出处，RAG 更便于检查这些证据。微调不是必然无效，但会引入训练数据、算力和评估负担，超出已确认范围。本项目复用现有模型与 API，不训练基础模型或额外重写模型。

请参照本版对应主题页或第16–20页备份。

这是限定领域的应用研究，贡献重点是带版本与位置的语料、人工校核基准、三类检索与两项消融的受控比较，以及失败分析。不能声称发明 RAG、提出新基础模型，或断言没有已有铁路问答研究。

请参照本版对应主题页或第16–20页备份。

## 4. BM25、Dense 和 Hybrid 有什么区别？

BM25 用词项匹配，适合专门术语和精确编号；Dense 用向量余弦相似度处理不同表达；Hybrid 将两种分数按既定规则归一化并融合。三者共享语料与预处理，最终看固定测试上的召回及答案质量。

请参照本版对应主题页或第16–20页备份。

## 5. 为什么 Hybrid 不一定更好？

相似向量可能匹配到缺少数值条件或不同版次的段落，归一化和融合也可能把错误候选提前。词法分数与语义分数是否互补，要由 B1/B2/B3 的逐题配对比较验证。没有提升时也应报告。

请参照本版对应主题页或第16–20页备份。

## 6. Evidence Gate 如何工作，能解决幻觉吗？

门控按内容词覆盖率或原始 cosine 超过相应阈值接受证据，阈值只由开发集选择。它是启发式筛选，可能误拒绝，也可能接受表面相关但无语义支撑的内容，不能宣称消除幻觉。用无支撑回答发生率、合理拒答召回、误拒答及人工判分共同衡量。

请参照本版对应主题页或第16–20页备份。

## 7. 如何确认标准版本正确？

先核对来源、正式编号、年份和正文版本信息，保留哈希和原文位置，重复文件不算不同版本。查询指定版本时按编号及年份限制候选，缺版拒答，歧义澄清。评价包括缺版题，并按版本可用性分层同时报告回答覆盖。

请参照本版对应主题页或第16–20页备份。

## 8. 100 道题足够吗？

这是本科项目在人工原文核对工时约束下的计划规模，20 道开发、80 道测试，不能宣称具有广泛统计代表性。覆盖不同问题类型并保持事实/对话组不跨划分，报告计数、配对差异和不确定性。子集很小时限制结论；不看测试结果反向改题或调参。

请参照本版对应主题页或第16–20页备份。

## 11. 如果 Embedding API 无法使用怎么办？

先保留错误记录，核对独立的地址、模型与授权配置，用合成或获准文本做真实接口小样验证。必要时按原 Proposal 的替代服务路径记录变更，并统一重做受影响比较。可保留本地 BM25 检索作为有限演示，但不能称 RQ1 或在线问答验证已经完成。

请参照本版对应主题页或第16–20页备份。

## 12. 如果两个系列各两个正式版本凑不齐怎么办？

先寻找获准文本或替换候选系列，不把重复副本、扫描件或草稿充作有效版本，不新增 OCR。若仍不足，保留 A1，明确限制 RQ2 为可支持的有限案例，并报告可用版本数量及范围，不能假造版本或声称广泛有效。

## 13. 如何处理版权、隐私和外部 API 风险？

请参照本版对应主题页或第16–20页备份。

## 15. 如何避免数据泄漏和主观判分？

相关事实和对话留在同一划分，参数只由开发集选择；测试前冻结数据、代码、提示词与模型设置。依据固定原文和同一 rubric 评分，尽可能遮蔽配置标签并复核疑难项。这里不声称双人标注，也不使用 LLM judge。

请参照本版对应主题页或第16–20页备份。

## 16. 为什么 Recall@5 要使用门控前排名？

这样衡量检索本身是否找到 gold 证据，避免把门控拒绝与检索失败混在一起。门控后的影响通过答案正确率、无支撑回答及拒答指标分析。六十四道可回答题全部保留，无命中或检索失败记零。

请参照本版对应主题页或第16–20页备份。

## 17. 引用正确是否就等于答案正确？

不是。编号存在、摘录匹配是结构检查，不能证明该段话支持结论。人工还要核对事实、数值、单位和条件。Citation Support 按被引用声明计，同一声明的多条引用联合判断，并另报引用覆盖率，避免只引用容易部分。

请参照本版对应主题页或第16–20页备份。

## 18. 是否已经达到80%准确率？

没有。Recall@5 和完全正确率至少0.80、引用支撑至少0.90等均是计划目标。正式评测尚未开展。最终应如实报告结果与局限，不能为达到目标而删题或选择有利输出。

请参照本版对应主题页或第16–20页备份。

## 19. 为什么不追求系统永远作答？

标准查询中，缺版或缺证据时猜测容易造成误导。但全部拒答也不能算好系统。因此用不可回答题的拒答召回与可回答题的误拒答率一起评价，并报告回答覆盖率。

请参照本版对应主题页或第16–20页备份。
