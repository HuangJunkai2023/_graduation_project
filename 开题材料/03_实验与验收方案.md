# 实验与验收方案 v0.2（2026-10-14 修订）

这是开题阶段的预先设计，不包含实测问答结果。先完成数据核查与开发集调试，再冻结正式测试。参考代码提供的伪向量自检只能用于实现正确性检查。

## 问题集与划分

| 类别 | 开发集 | 测试集 | 标注内容 |
| --- | ---: | ---: | --- |
| 条文、条件或参数查询 | 6 | 24 | 答案、适用条件、单位、证据位置 |
| 术语解释 | 3 | 12 | 定义及依据位置 |
| 指定标准/版本查询 | 4 | 16 | 请求的标准及年份、证据位置 |
| 简单追问 | 3 | 12 | 对话上下文、独立问题释义、依据位置 |
| 不可回答问题 | 4 | 16 | 缺失版本/库外内容/无关问题/版本或指代冲突及不可回答理由 |
| 合计 | 20 | 80 | 每条实际计分的问题均须人工检查 |

计数单位是一条待评估问题。追问的上下文作为输入保存，不另计作评测题；如上下文本身也要评分则单列题目。不可回答题中各安排 4 道缺失版本、库外领域问题、完全无关问题和信息不足/版本线索冲突问题。开发集每类各 1 道。

按标准家族或同源条文归组；同义改写、同一事实和关联对话不能跨开发/测试集。测试集中的证据文档仍在共同知识库中：本研究考察固定知识库的检索与问答，不声称评估对全新文档的泛化。先人工分层分组实现上述配额，再固定题号、划分和文件 SHA-256；不得为凑配额拆散同一事实组。

每个题目保存：`question_id`、`split`、`category`、`group_id`、`question`、`history`、`answerable`、`reference_answer`、`required_facts`、`evidence_units`、`unanswerable_reason`、`review_status`、`requested_standard`、`requested_edition`、`edition_stratum`、`expected_action`。版本分层为 available / missing / ambiguous / not_applicable；只有 unambiguously specified 的 available/missing 题进入错版本率分母。冲突版题预先标 expected_action=clarify，不将其混入可回答题。每个证据单元包括稳定文档 ID、标准号/年份、PDF 文件页码或 DOCX 段落/表格编号、必要文本片段。库外问题不虚构 gold evidence。

人工标注分两步：先依据原文写出必要事实和定位，再复核问题是否唯一可判定。需补充、相互矛盾或标注存疑的问题留在待修订区，不进入冻结集。不把模型生成的答案未经核验当作标准答案。两次自审有间隔并记录修改；若导师或领域人员参与复核，记录实际参与方式，不预先声称双人标注或专家一致性。

## 实验配置

| 配置 | 检索 | 版本约束 | 证据检查 | 用途 |
| --- | --- | --- | --- | --- |
| B1 | BM25 | 开 | 开 | RQ1 对比基线 |
| B2 | 向量 | 开 | 开 | RQ1 对比基线 |
| B3 | 混合 | 开 | 开 | 完整改进配置 |
| A1 | 混合 | 关 | 开 | RQ2 消融 |
| A2 | 混合 | 开 | 关 | RQ3 消融 |

RQ1 另报告共同候选条件下、证据检查前的原始检索指标，避免拒答把召回差的题移出分母。A1 保留标准家族候选约束、来源版本标签、draft 排除、分词和排名；只关闭年份限制及与之配套的缺版/多版提前返回。当前代码 edition_filter=False 会同时关闭家族和年份筛选，尚不满足此单因素消融，必须在 T08 修改并验证后冻结；本次仅修订研究计划，不声称该代码差异已修复。A2 仅关闭检索阶段的证据门槛，保留生成提示词、模型自身拒答、引用校验、输出解析及错误处理。因此 RQ3 的消融结论限定为该检索门槛的增量作用，不能当作移除全部可靠性机制的结果。基线比较不采用不同语料或不同生成模型。

中文预处理（计划在冻结前统一）：索引与查询采用同一现成中文分词工具（如 jieba）和小型专业词典，保留标准号、术语、数字和单位；不训练模型。词典、标准号规范化规则、工具版本及停用词表随配置冻结。Evidence Gate 的 lexical coverage = 命中片段词元的去重查询内容词元数 / 全部去重查询内容词元数；计算该比例时去除标准标识和固定停用词，空集合记 0，按同一分词结果匹配。标准号仍保留用于索引与版本筛选。当前原型使用中文 1–3 字符 n-gram 和子串覆盖率，尚未实现上述正式实验分词口径；在现有检索/门控完善任务中统一，不新增配置组或训练任务。

固定：语料、切块、Top-K=5、生成模型、embedding 模型、提示词、温度、最大输出长度与评分规则。BM25-only 不调用 embedding 进行查询。每题对同一合格候选全集分别做 min–max 归一化 (s−min)/(max−min)；常量正分映射为 1，其他常量映射为 0，与当前 normalize 实现一致。混合为 (1−w)×BM25_norm+w×cosine_norm，w∈{0.25,0.50,0.75}；按 16 道可回答开发题 Recall@5 最大、继而 MRR@5 最大选择，仍并列时优先 0.50，其次 0.25、0.75。冻结前保存候选全集定义、原始与归一化分数、分词规则、BM25 k1=1.5/b=0.75、切块与重叠、embedding 标识和参数。原教学实现另外留存运行记录，不把其所有行为与 B1/B2 混同。

只对通过数据使用条件检查的资料调用在线接口。先小样本估算：建库 embedding 量 + 查询 embedding 量 + 400 次正式测试运行 + 100 次开发集一轮运行所需的最多 500 次初次生成调用，另加最多 100 次调试/恢复调用；以供应商实际计费单位换算，不把中文字数直接当 token 数。冻结后每组完整跑一次并保留原始日志；不安排例行测试重复采样。接口失败保留原结果，恢复运行另记 attempt_id，预先决定主分析采用首次尝试并另报恢复结果，禁止择优替换。在线请求预算包括重试；一次逻辑运行不等于必定调用一次生成接口。缺版、澄清、证据拒答可提前结束。

## 指标定义

| 指标 | 定义与分母 |
| --- | --- |
| Recall@5 | 对每个可回答问题，前 5 个检索片段覆盖的 gold 证据单元数 / 该问题 gold 证据单元数，再对题目宏平均。重叠切片不能重复记同一证据单元。 |
| MRR@5 | 每个可回答问题首个相关证据的排名倒数；前 5 无命中为 0，再取平均。 |
| 答案正确率 | 可回答问题中，必要事实正确、条件/单位/版本正确且无关键虚构的完整正确回答比例；错误、空答案、误拒答和 API 失败均不算正确。 |
| 引用支撑率 | 以所有已展示回答中有引用的原子事实断言为分母，其中被该断言整组引文共同充分支持的断言为分子；同一句多引文只计一次。数值、单位、条件、版本均须一致。另报引用覆盖率＝有引用断言数/全部事实断言数，以及引用正确性；无断言为 N/A。 |
| 无依据回答发生率 | 全部 80 道测试题中，已展示实质回答含至少一条无依据事实的题数 / 80；同时报告有回答题中的条件比例及回答覆盖率，避免全部拒答显得可靠。 |
| 引用可解析率 | 所有输出引用中，能定位到本次检索证据和原始位置的比例。它与语义支撑率分开统计。 |
| 错版本率 | 集合 E 为请求单一明确版本的题，包含该版本已入库及缺失两类；给出基于非请求版本的实质答案即错版，附“仅供参考”也不免责。分母是全部 E 题（不是仅回答题）；分别报告 available/missing 分层样本数和回答覆盖率。纯版本列表/解释缺失不算实质错版答案。冲突线索题不入 E，单独评价是否要求澄清。 |
| 拒答召回率 | 全部 16 道不可回答测试题中，按 gold expected_action 正确说明证据/版本缺失或对标注歧义请求澄清的比例；不得同时输出无依据实质答案。API、格式/引用失败和空输出不算正确拒答。 |
| 误拒答率 | 全部 64 道可回答测试题中，拒绝回答或不必要地要求澄清的比例；partial 有实质答案则另按完整正确率记分，不能因漏答改作合理拒答。API/格式错误单列为错误，不归为拒答。 |
| 可用率与延迟 | 全部运行中成功完成比例；检索、生成和端到端耗时分别报告中位数及 P95。API 失败记录类型、耗时和次数，不静默删除。 |

自动判定的相关片段必须同时满足文档版本、位置及必要证据覆盖；仅同文件/同页不自动算命中。对一页内多个条文或跨页条文，使用人工标注的文本范围核对。分母为 0 时输出 N/A，不能输出 100%。

开发集用于确定判定细则；正式比较对相同题目成对进行。报告总体与各类别的样本数、指标和绝对差值。对总体指标差值按 `group_id` 作成对 bootstrap（固定 seed=3801，2000 次），报告 95% 区间并说明测试集规模较小；不将小样本差值直接称为显著提升。人工判分时隐藏配置标签，保留逐题判分理由。

## 必测功能和异常

- 文本 PDF 可提取并保留文件页码；扫描空页、混合页、损坏文件有明确报告。
- DOCX 表格/段落可定位；`.doc` 不能直接当成 `.docx` 解析。
- 标准号包含空格、不同斜杠、连字符、分册号和年份时归一化一致；来源保留原始标签。
- 指定版本存在、缺失，以及未指定版本但存在多个版本时，行为明确且可解释。
- 检索没有相关证据时拒答；部分证据时说明未覆盖部分；答案出现不存在的引用编号时不得直接展示为正常成功。
- 简单追问能继承主题；无法确定指代时澄清；清空会话后历史不影响检索。
- API Key 缺失、限流、超时、空返回分别记录错误；不把错误计为合理拒答。
- 文档包含“忽略规则”等指令时，不执行文档指令；本地示例不启动工具执行。

## 验收材料

每次实验保存配置快照、数据/评测集哈希、模型标识、执行环境、运行时间、每题证据排名和分数、答案/引用、状态、分段耗时及人工评分。最终交付对比表、消融表、至少 3 个成功和 3 个失败案例，以及可重跑说明。

Proposal 中的阈值为拟议性能目标。若未达到，报告差距和原因；不能删掉困难问题或修改测试集来使指标达标。系统完成与方法是否优于基线分别评价。

## 门槛、版本语料与标注工时

证据门槛使用 content_terms 的词面覆盖率 ≥ τL，或（该模式有向量时）原始余弦 ≥ τD。两者是启发式值而非置信概率；不用归一化融合分判断“证据充分”。计划小网格 τL∈{0.05,0.10,0.20}、τD∈{0.20,0.30,0.40,0.50}。对 20 道开发题三种基线的 Top-5 候选，利用 gold 证据核验 passage relevance 标签，选择平均 passage F1 最大的同一门槛对；并列时先低假拒答，再较高 precision，再按预先固定的网格顺序。保存标签、逐配置结果及选择依据；不得看测试集选门槛。网格检索可重用向量缓存，不能把每个网格点都变成一轮付费生成。无论计划目标是否达到，冻结后都报告结果。

语料目标包含至少两组同一标准不同正式版本，每组至少两版，以文档封面/发布记录核对版次。不同编码/扫描副本即使哈希不同，也不是不同版；通过标准号、年份、名称和内容核对去重。两个版本条文没有实质差异时可测试版本定位，但不能声称测得冲突条文辨别能力；需保留真实不同的要求或明确版本证据。

2026-10-14 本地抽查 TB/T 2073、2074 的 2010/2020 候选：2020 文本可提取，2010 候选均无可提取正文。封面显示 2020 替代 2010，但使用许可、完整解析质量及足够可用版对仍待核实。2003 扫描件和 2009 报批稿不能直接充当可用正式版。优先寻找获准的文本版或更换到其他接触网相关标准家族，不增加 OCR 范围。到 M2 仍无足够版对时，A1 仍执行，RQ2 如实写为小样本/缺版处理案例及限制；合成版冲突仅验证代码，不能混入主测试获得实证结论。任何题型配额调整在冻结前记录，不能重复同一条文凑数。

T07=36 小时：schema/试标 4h + 100 题初标 20h + 分开复核 10h + 分组划分 2h。T12=40 小时：运行/日志 4h + 400 输出初评 20h + 80 项抽样/疑难复核 6h + 分析 6h + 缓冲 4h。这是尚待计时试验验证的估算，不是已完成工时。每题限制为 1–3 条必要事实，评分表统一为 correctness、support、edition、refusal、failure_type、reason。配置标签隐藏，按预先生成的随机顺序呈现；完全相同的答案和同一证据集合可复用人工判断，但保留每条运行与 score_id 对应，不能复用只文本相似或证据不同的结果。不声称双人标注或专家一致性。

首轮试标 10 道开发题并试评其五配置输出，测中位耗时；不得为试标消耗正式测试题。超时优先压缩可选重复运行、使用缓冲或经导师讨论调整问题宽度，不能削掉人工核验。分析采用每题首轮输出作为主结果；句子/事实细分规则在开发集上定稿。生成与向量费用为 £35+£10，预备 £5，总上限 £50，达到 £40 复核；API 价格、token 用量和汇率须在真实小样本试跑后记录。
