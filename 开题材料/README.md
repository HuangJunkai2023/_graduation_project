## 使用与更新

英文 Markdown 是 Proposal 正文源文件；CSV 是进度源文件。修改后可以重新生成 DOCX 和图，但不要在同时手工修改 DOCX 后直接重生成，否则派生文件中的手工更改会被覆盖。原始学校模板不会被覆盖。

```bash
# 在工程根目录；使用本次创建的隔离环境
.venv/bin/python 开题材料/tools/audit_materials.py
.venv/bin/python 开题材料/tools/build_documents.py
```

运行环境版本见 `数据核查/环境版本.json`。重建环境可使用 `tools/requirements.txt`；两脚本均不需要 API Key。审计脚本会重新抽查本地原始文件并更新核查输出；修改候选或抽样规则后也要同步修订人工说明。

Section 1 字数及 DOCX 结构校验见 `数据核查/文档校验.json`。环境没有 Word/LibreOffice，尚未验证 Word 实际分页；提交前请在 Word 中检查排版与字数。学校的七页限制适用于最终报告，不是本开题 Proposal。

文献链接已在源稿及 Word 中提供。AI 辅助草稿须由学生理解、核查并按学校要求使用与说明；未发生的工作、反思、认可或签名不得填写为已完成。
