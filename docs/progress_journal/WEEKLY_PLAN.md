## 五组配置与可复现性底线

| 配置 | 检索 | 版本处理 | 检索Evidence Gate | 其他控制 |
| --- | --- | --- | --- | --- |
| B1 | BM25 | 开启 | 开启 | 同一冻结语料、问题、生成模型/prompt、Top-K=5和引用检查 |
| B2 | Dense | 开启 | 开启 | 同上 |
| B3 | Hybrid | 开启 | 开启 | 同上；作为消融参照 |
| A1 | Hybrid | 保留标准家族；关闭年份限制、缺版和版次歧义检查 | 开启 | 与B3仅改变版次处理 |
| A2 | Hybrid | 开启 | 关闭 | 保留生成提示、引用编号/原文检查及错误处理；不等于关闭所有安全措施 |

Hybrid按eligible chunks的BM25与cosine分数分别min–max，再以 `(1−w)B+wD` 融合。常数正值映射1，其余常数映射0；开发集在`{0.25, 0.50, 0.75}`选w，先Recall@5再MRR@5，平局优先0.50。门槛也只用开发集；Week 13/15探索，Week 17定稿并冻结。中文分词、专业词典、stopwords及coverage规则须与Proposal一致，不能只冻结数值参数。

100题目标为20开发题（16可回答、4不可回答）和80测试题（64可回答、16不可回答）；按相关事实和对话组隔离，不用测试结果优化方法。gold保留标准/年份、原文位置、连续摘录、1–3项必要事实及单位/适用条件，AI辅助起草不能替代人工核验。开发题试标先开展，正式测试的参数选择和模型输出不能反过来修改gold。标注本身需要查看原文，但测试集不得用于调参。

| 指标 | 固定口径 |
| --- | --- |
| Recall@5 / MRR@5 | 64个可回答测试项，使用门控前排名；gold匹配包括文档、位置与原文证据。无命中或检索失败记0。 |
| Answer correctness | 完全正确题数 / 64；错误、拒答或API失败不能移出分母。 |
| Citation support | 人工判断受引用支撑的已引用claims / 全部已引用claims，联合判断同一claim的引用；另报citation coverage，无claims不能视为100%。 |
| Wrong-edition rate | 使用非请求版次的回答数 / 所有无歧义指定版本题数（含缺版）；同时按版本可用性分层，并报告回答覆盖，避免拒答掩盖问题。 |
| Refusal recall | 合理不作答数 / 16不可回答项；仅预先标注的歧义项可合理澄清，API/格式错误不是合理拒答。 |
| False refusal | 拒答或不必要澄清数 / 64可回答项。 |
| Unsupported-answer incidence | 按固定人工规则判断的无支撑回答题数 / 全部80测试项，配合错误/回答覆盖共同解释。 |

零分母记N/A，另列样本数；所有指标目标是计划目标，不填入实验结果栏。人工判分隐藏配置标签；相同答案且证据完全相同才可复用已核判断，保留每条运行与score ID的对应，不声称双人标注。

T12计划400个正式测试执行；20开发题跨五配置再加100个执行，首轮生成上限为500次，另外100次预留，合计最多600次计划新增生成。早期拒答可能不生成；重试仍记录原失败，不新增评分题。向量构建/查询费用另计，开发检索参数探索重用缓存，不常规重复正式测试。£35生成＋£10向量＋£5预备＝£50计划上限，达到£40复核；真实费用按当时账户单位/用量记录。
