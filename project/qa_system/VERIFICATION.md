## 实际验证的用户流程

用户在本地 Streamlit 页面提问 → Python 问答链路 → SQLite 中的规范文本 → BM25 检索与版本检查 → 展示原文来源及 PDF 页面。

| 边界 | 结果与证据 |
| --- | --- |
| 服务启动 | 监听 `127.0.0.1:8501`，`/_stcore/health` 返回 `ok` |
| 浏览器渲染 | Google Chrome 无头浏览器实际打开页面，无捕获到的页面 JavaScript 异常 |
| 界面 → 检索 → 来源 | 输入“TB/T 2073-2020 对零部件表面质量有什么要求？”后，显示检索结果及 PDF 文件第 7 页等来源 |
